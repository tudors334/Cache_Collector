Acesta este proiectul nostru la materia CN, despre functionarea si implementarea unui Cache Collector Controller care se foloseste de generarea aleatoare a variabilelor. Aspectul aleator al programului in ceea ce priveste atat accesele la memorie, dar si adresele propriu-zise se datoreaza scriptului necesar rularii wave_setup.do ce genereaza o variabila in functie de timpul rularii, dand aspectul pseudo-aleator al programului. Se foloseste de functiile standard de Verilog pentru variabile aleatoare ($random). Rularea programului fara acest script duce la un comportament neasteptat al codului, eronat.
